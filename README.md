# FETCH — an open feed of public grant and funding opportunities, organized for discovery

FETCH is an open organization data feed. It collects publicly posted grant,
funding, and procurement opportunities from public sources — federal and state
opportunity portals and public funder listings — and organizes them into
clean, structured, searchable records, so that small organizations,
independent builders, and community groups can discover opportunities they
would otherwise never see. Finding funding is currently a scavenger hunt
across dozens of disconnected portals; FETCH exists to turn that public
information into open tooling for opportunity discovery that anyone can build
on.

The project is open source and developed in the open. Its intake pipeline
already runs: public feeds are polled on a schedule and every captured
opportunity is stored as a structured record with its source, deadline, and
evidence preserved. The work now is hardening — validation, completeness
checks, and small, well-tested tools around the feed.

**Project listing:** DemocracyLab Project 2152 —
https://www.democracylab.org/projects/2152

**Skills sought:** Python developers; data wrangling / data quality;
technical project management (keeping small work orders scoped and reviewed).
All levels welcome on the first work order.

**Current stage:** Working prototype with a live intake pipeline and a
growing record set; pre-release, developed by a single maintainer with
volunteer help.

**Time expectations:** Volunteer-paced. The first work order is sized at a
few hours total. Ongoing help, if a volunteer wants it, is a few hours a week
at most — small, frozen, individually reviewable tasks rather than open-ended
commitments.

**Terms:** This is a volunteer, unpaid open-source contribution to a public
project. No payment is offered or promised. Volunteers keep full credit for
their contributions in the public record.
