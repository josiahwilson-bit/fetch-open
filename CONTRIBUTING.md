# Contributing to FETCH

FETCH work is delegated in small, frozen work orders and reviewed against a
fixed scope before acceptance (the Delegation Evidence Standard):

1. **Freeze scope** — each work order is fixed in writing before work starts;
   any change means a new version.
2. **One issue per work order** — the issue carries the scope, the reviewer,
   and the acceptance criteria.
3. **Pull request with evidence** — a PR linked to the issue, listing commit
   IDs and changed files, with tests included and passing, and a short
   explanation mapping each change to the acceptance criterion it satisfies.
4. **Validation recorded** — findings are recorded as matched / missing /
   extra / uncertain. A commit proves a recorded code change only — not
   completion, acceptance, or deployment.
5. **Acceptance is separate** — the maintainer records acceptance as its own
   step after review.

All contributions are volunteer and unpaid. Contributors keep full credit
for their work in the public record.
